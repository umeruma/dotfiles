## install (macOS / Linux)

実行前にスクリプトの中身を確認します: 

> [https://dot.umeru.ma/install](https://dot.umeru.ma/install)

Terminal.app を開いて実行:

```
bash -c "$(curl -fsSL https://dot.umeru.ma/install)"
```

bash と curl のオプションのメモ:

bash:
- `-c`: 渡した文字列を bash コマンドとして実行する（例: `bash -c "echo hello"` は `hello` を出力）

curl:
- `-f` (`--fail`): HTTP エラー（4xx/5xx）のときはエラーページを出力せず、非ゼロで終了する
- `-s` (`--silent`): 進捗バーやエラーメッセージを表示しない
- `-S` (`--show-error`): `-s` と組み合わせると、エラーメッセージだけは表示する
- `-L` (`--location`): リダイレクト先までたどってダウンロードする

インストール実行後、dotfiles リポジトリは `~/Codes/dotfiles` にcloneされます。すでに存在する場合はHEADをpullしてインストール処理を実行します。

インストーラーは [`mise bootstrap`](https://mise.jdx.dev/bootstrap.html) を実行して、定義されているmacOS用のdefaultsの適用を行ったのち、`$HOME`へのdotfilesのデプロイを行います。詳細は、 [mise bootstrap](/mise-bootstrap)。

## jump to dotfiles (on all platform)

.zshenv と .zshrc にこのような定義があり、
```
# on .zshenv
export DOTFILES="$HOME/Codes/dotfiles"

# on .zshrc
alias dot='cd $DOTFILES' 
```

ターミナルで`dot`を実行することで、dotfiles ディレクトリにすぐ移動できます。

## Deploy dotfiles

dotfiles をホームディレクトリにデプロイするには:

```
dot && mise run deploy
```

### How it works

symlink は mise の `[dotfiles]` セクションで宣言的に管理しています。
- for all platform [`mise.dotfiles.toml`](https://github.com/umeruma/dotfiles/blob/main/mise.dotfiles.toml)
  - `.miserc.toml` の `env = ["dotfiles"]` により全ての環境で適用される
- for macOS [`mise.macos.toml`](https://github.com/umeruma/dotfiles/blob/main/mise.macos.toml)
- for macOS & Linux [`mise.unix.toml`](https://github.com/umeruma/dotfiles/blob/main/mise.unix.toml)
- for Windows [`mise.windows.toml`](https://github.com/umeruma/dotfiles/blob/main/mise.windows.toml)

```toml
# 登録内容の一例
[dotfiles]
"~/.zshrc" = { source = "home/.zshrc", mode = "symlink" }
```

デプロイしているファイルの他に、アプリケーションがログファイルやコンフィグファイルを吐き出すディレクトリ（例: `~/.config/karabiner`、`~/.config/micro`、`~/.config/lazygit`、`~/.config/herdr`）は**ファイル単位**でリンクし、ログファイル等はリポジトリ管理されないようにしています。静的な設定ディレクトリ（`~/.config/ghostty`、`~/.config/sheldon`）はディレクトリごとリンクしています。

`~/.config/nvim` は例外で、ディレクトリごとリンクしています。LazyVim のプラグインバージョンが `lazy-lock.json` git で追跡されるようにするためです。詳細は: [Editor Stack](/editor-stack)

よく使うコマンド:

```
mise dotfiles status   # 各設定の applied / differs / missing を表示
mise run install-apps  # Burewfileに登録したアプリケーションの登録
dottrack <path>        # 既存ファイルのリポジトリ管理の開始

brew bundle add --cask [app name]
  # リポジトリで管理するbrew caskアプリケーションの登録
```

## Terminal theme (cendre)

Ghostty（macOS）のテーマは deploy コマンドで適用される。`theme = cendre`。Terminal.app / Windows Terminal は opt-in で、明示的にコマンドを実行する:

```
dot && mise run theme
```

- macOS: [cendre](https://github.com/Aejkatappaja/cendre) の `extras/macos-terminal/cendre.terminal` を開いてプロファイルを取り込む（切り替えは Terminal.app の設定で）
- Windows: Fragments にスキームを置き、`settings.json` の `profiles.defaults.colorScheme` を `cendre` にパッチ（Terminal 再起動で反映）
