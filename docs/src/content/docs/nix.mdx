## Overview

macOS のパッケージ、GUI アプリ、zsh の設定、dotfiles のリンクは、すべて [`flake.nix`](https://github.com/umeruma/dotfiles/blob/main/flake.nix) に宣言しています。反映は `mise run switch` の1つだけです。

| File | 役割 |
| --- | --- |
| `flake.nix` | 入力（nixpkgs、nix-darwin、home-manager、nix-homebrew など）と `darwinConfigurations.AME` |
| `nix/darwin.nix` | システム側の設定 |
| `nix/homebrew.nix` | Homebrew 本体（nix-homebrew）。各ツールの cask と App Store アプリを集めて入れる |
| `nix/home-manager/default.nix` | `tools/` の全ファイルを読み込む。`my.casks` などのオプションを定義 |
| `nix/home-manager/dotfiles.nix` | ツールに属さないリンクと、`~/.config` のまるごとリンク |
| `nix/home-manager/tools/*.nix` | ツールごとに1ファイル |

`tools/` の1ファイルには、一緒に足して一緒に消すもの（アプリ、CLI、zsh の alias や関数、設定ファイルのリンク）をまとめて書きます。ファイルを消せば、全部まとめて消えます。

## Switch

```
dot switch
```

nix-darwin、home-manager、Homebrew の順に反映し、宣言から消したリンクも外します。

- `sudo` を使うので、自分のターミナルで実行します。Claude Code の `!` からはパスワードを入力できません。
- `~/.config` が空でないディレクトリのままだと、switch は止まります。中身を `home/.config` に移してから実行します。

## Add a tool

入れ方は、上から順に探します。

1. **nixpkgs**: CLI は `home.packages`、GUI アプリは `my.apps`（`/Applications/Nix Apps` に入る）。探すときは `nix search nixpkgs <name>`。
2. **ほかの flake**: `flake.nix` の `inputs` に足す（例: `crit.nix`）。
3. **Homebrew cask**: `my.casks`。formula は `my.brews`。nixpkgs にないもの、ドライバやシステム拡張を入れるもの、自己更新でデータを移行するもの（Raycast）。
4. **App Store**: `my.masApps`。ID は `mas list` で調べる（`app-store.nix`）。
5. **GitHub Releases など**: `fetchurl` で取ってくる（例: `azookey.nix`）。

zsh の alias や関数は、同じファイルに書きます。ツールが `~/.config` に書き込む状態ファイルや認証情報は、`my.configIgnore` で除外します（[Config ignore](#config-ignore)）。Claude Code のプラグインは `my.claudePlugins` に `"plugin@marketplace" = "owner/repo"` の形で書くと、switch のときに入っていなければ入ります（例: `revdiff.nix`）。HTTP の MCP サーバーは `my.claudeMcpServers` に `name = "url"` の形で書くと、user スコープに追加されます（例: `rex.nix`）。

```nix
# nix/home-manager/tools/keka.nix
{ pkgs, ... }:
{
  my.apps = [ pkgs.keka ];

  programs.zsh.shellAliases.keka = "${pkgs.keka}/Applications/Keka.app/Contents/MacOS/Keka --cli";
}
```

設定もエイリアスもない GUI アプリは、`apps.nix` にまとめます。

新しいファイルは、switch の前に `git add` します。flake は git が追跡していないファイルを読みません。

### Disable a tool

一時的に外すときは、拡張子を `.nix` 以外に変えて switch します。`default.nix` は `tools/` のうち `.nix` で終わるファイルしか読みません。ファイル名の頭に何か付けても外れません。

```
git mv nix/home-manager/tools/foo.nix nix/home-manager/tools/foo.nix.off
dot switch
```

戻すときは名前を戻して switch します。外している間も、Homebrew で入れたものは残ります（次の節）。

### Remove a tool

ファイル（または行）を消して switch します。パッケージ、zsh の設定、`home.file` のリンクはこれで消えます。ツールの設定ファイルのリンクも、`dotfiles.nix` ではなくそのツールのファイルに書きます。

次のものは switch では消えないので、手で片付けます。

| 残るもの | 理由 | 片付け方 |
| --- | --- | --- |
| Homebrew の cask・formula・App Store アプリ | 手で入れたアプリまで消さないよう、`cleanup = "none"` にしている | `brew uninstall --cask <name>` など |
| Claude Code のプラグイン（`my.claudePlugins`） | `~/.claude/plugins` は Claude Code が管理している | `claude plugin uninstall <plugin>@<marketplace>` |
| Claude Code の MCP サーバー（`my.claudeMcpServers`） | `~/.claude.json` は Claude Code が管理している | `claude mcp remove -s user <name>` |
| `flake.nix` の `inputs`（crit、revdiff、k） | inputs は flake にしか書けない | 該当の input を消して `nix flake lock` |
| `home/.config/<tool>/` | `~/.config` をまるごとリンクしているので、ツールのファイルとは別に repo にある | ディレクトリを消す |
| `home/.agents/skills/<skill>` と `claude.nix` の `skills` | スキルは Cursor や Copilot と共有している | 使わなくなったら両方から消す |

## Config ignore

`home/.config/.gitignore` は生成物です。switch のたびに、各ツールのファイルの `my.configIgnore` を集めて書き出します。手で直しても上書きされるので、行はツールのファイルに書きます。

```nix
# nix/home-manager/tools/gh.nix
my.configIgnore = [ "gh" ]; # ~/.config/gh（認証情報）
```

- パスは `~/.config` からの相対で書きます。
- `tools/` にファイルがないアプリの分は、`dotfiles.nix` にまとめます。
- 生成したファイルも git で追跡します。clone した直後、まだ switch していない状態でも、認証情報が untracked として見えないようにするためです。
- シンボリックリンクではなく実ファイルとして書き出します。git は、作業ツリー内でシンボリックリンクになっている `.gitignore` を読まないためです。

## Update

| What | How |
| --- | --- |
| nixpkgs などの入力 | `nix flake update` のあと switch。1つだけ上げるなら `nix flake update <input>` |
| タグで固定した入力（crit、revdiff） | `flake.nix` のタグを書き換え、`nix flake update <input>` のあと switch |
| cask | switch では上げない（`upgrade = false`）。アプリの自己更新に任せるか、`brew upgrade --cask <name>` |
| App Store | App Store に任せる |
| `fetchurl` で固定したもの（azooKey） | `version` と `hash` を書き換えて switch |

`hash` は次のコマンドで取れます。古いまま switch しても、エラーに正しい値が出ます。

```
nix store prefetch-file <url>
```
