[Doom Emacs](https://github.com/doomemacs/core) は core と設定を分けて管理している:

| Path | Role |
| --- | --- |
| `~/.config/emacs` | Doom core（[doomemacs/core](https://github.com/doomemacs/core)）。`mise run setup-doom` が clone する |
| `~/.config/doom` | Private config（`init.el`、`config.el`、`packages.el`）。このリポジトリから mise `[dotfiles]` でデプロイ |

## Prerequisites

`mise run install-apps`（macOS Brewfile）でインストールされる:

- `emacs`
- `ripgrep`
- `fd`

## Setup

```bash
mise run deploy        # dotfiles から ~/.config/doom を symlink
mise run install-apps  # emacs が未インストールの場合
mise run setup-doom    # core を clone（必要なら）して doom install を実行
```

`setup-doom` は冪等: `~/.config/emacs` が既にあれば clone をスキップし、必要なら `sources/doom+` submodule を初期化してから `doom sync --force --env` を実行する。

初回の sync は通常 **5〜15 分** かかる（大量の git clone が走るため）。それ以上出力なしで止まっている場合は、`sources/doom+/modules` が存在するか、他の `doom` / `emacs` プロセスが入力待ちになっていないかを確認する。

## Daily use

- 起動: `emacs`
- `init.el` や `packages.el` を編集したら: `doom sync`
- macOS GUI: 環境スナップショットはセットアップ時に生成される（`doom install --env`）。`PATH` が変わったら `doom sync --env` を再実行
- トラブルシュート: `doom doctor`

`doom` CLI は `~/.zprofile`（`~/.config/emacs/bin`）で `PATH` に入る。

## Customize

このリポジトリの `home/.config/doom/` 以下を編集して:

```bash
mise run deploy
doom sync
```

モジュール一覧: Emacs 内で `SPC h d h`、または [Doom docs](https://github.com/doomemacs/core/tree/master/docs) を参照。

## Learning (Emacs / Doom)

この dotfiles では **Evil**（Vim スタイルのキー操作）を有効にしている。リーダーキーは **`SPC`**（スペース）。

| Resource | What it covers |
| --- | --- |
| [Doom: Getting Started](https://github.com/doomemacs/core/blob/master/docs/getting_started.org) | インストール後の流れ、日常のワークフロー、設定の基本 |
| [Doom: FAQ](https://github.com/doomemacs/core/blob/master/docs/faq.org) | よくある質問と対処 |
| [Doom documentation site](https://docs.doomemacs.org/) | 検索できるモジュール / API ドキュメント |
| [GNU Emacs guided tour](https://www.gnu.org/software/emacs/tour/) | Emacs とは何か（エディタ非依存の入門） |
| [Emacs built-in tutorial](https://www.gnu.org/software/emacs/manual/html_node/emacs/Tutorial.html) | クラシックなキーバインド（Emacs 内で `C-h t`） |

起動後に便利なコマンド:

- `SPC h b b` — キーバインド一覧
- `SPC h d h` — Doom のヘルプ / モジュール索引
- `C-h t` — Emacs チュートリアル（非 Vim キー）
- `M-x` — 任意のコマンドを名前で実行（Evil モードでは `SPC :`）
